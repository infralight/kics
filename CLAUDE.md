# kics

## Project Overview
Fork of Checkmarx KICS (Keeping Infrastructure as Code Secure) - Open source security scanner for IaC configurations.

## Purpose
- Find security vulnerabilities in IaC
- Detect compliance issues
- Identify infrastructure misconfigurations
- Early development cycle security scanning

## Supported Platforms
- **Terraform**
- **Kubernetes**
- **Docker**
- **CloudFormation**
- **Ansible**
- **Helm**
- **OpenAPI**
- **ARM**
- **Pulumi**
- And more...

## Architecture
- **Language**: Go
- **Packaging**: Docker/OCI image
- **CLI Tool**: Command-line scanner
- **Query Engine**: Custom security queries

## Features
- Multi-platform IaC scanning
- Custom security queries
- CI/CD integration
- Multiple output formats
- Pre-commit hooks
- Extensive documentation
